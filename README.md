DealScore — a Black Friday deal finder. 47 real Black Friday and Cyber Monday deals, each found and price-checked live on 27 Nov 2026, with its store, store link, sale price, usual price, discount, the dollar amount saved, a one-line evidence note, check time, source, and an honest verdict on whether it is really a deal. Searchable and filterable by category, store and discount, with the best deals first and the same product compared across stores.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
